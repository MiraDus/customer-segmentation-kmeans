# customer-segmentation-kmeans
K-Means clustering implemented from scratch (numpy, no sklearn) with custom Silhouette Score and cluster interpretation on the Mall Customers dataset
# Customer Segmentation: K-Means from Scratch

Кластеризация клиентов торгового центра по возрасту, доходу и тратам — алгоритм K-Means реализован с нуля (без sklearn), включая собственную реализацию Silhouette Score.

## Что сделано

- **Предобработка**: удаление выбросов по IQR, min-max нормализация признаков
- **K-Means с нуля** — вручную через numpy: инициализация центроидов, расчёт расстояний, итеративное обновление до сходимости
- **Собственная реализация Silhouette Score** (без sklearn) для оценки качества кластеризации
- Перебор числа кластеров k от 2 до 10, выбор оптимального k=8 по максимальному Silhouette Score (≈0.44)
- Визуализация кластеров в 2D и 3D
- Интерпретация каждого сегмента по среднему возрасту, доходу и тратам

## Данные

[Mall Customers Dataset](https://www.kaggle.com/datasets/vjchoudhary7/customer-segmentation-tutorial-in-python) — 200 клиентов торгового центра, признаки: возраст, пол, годовой доход, spending score.
